# 네트워크 환경 점검

AlliedID는 Wi-Fi와 네트워크 정보를 인터넷 사용이 아니라 "지금 이 컴퓨터가 어떤 네트워크에 노출되어 있는가"를 파악하는 데 쓴다. `AlliedID net` 으로 확인할 수 있다.

개방형 Wi-Fi(암호 없음)에서는 같은 네트워크의 다른 기기가 암호화되지 않은 트래픽을 볼 수 있다. 카페나 공항의 공용 Wi-Fi에서는 HTTPS 사이트만 쓰고, 가능하면 VPN을 켠다. WEP나 TKIP 같은 오래된 보안 방식은 쉽게 뚫리므로 WPA2 이상(가능하면 WPA3)으로 바꾼다.

Wi-Fi에 연결되어 있는데 인터넷이 안 된다면 캡티브 포털(로그인 페이지)이 있는지 브라우저로 확인한다. 신호가 30% 미만이면 공유기 가까이 이동하거나 5GHz 대신 2.4GHz 대역을 쓴다.

# 셀룰러 데이터와 테더링

휴대폰 테더링이나 LTE/5G 모뎀을 쓰면 통신사 요금제의 데이터가 소모된다. AlliedID는 셀룰러/테더링 경로를 감지하면 경고를 표시한다. 대용량 모델 다운로드는 Wi-Fi나 유선에서 하는 것이 좋다.
