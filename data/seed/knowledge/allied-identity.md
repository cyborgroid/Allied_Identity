# Allied Identity 소개

Allied Identity(줄여서 AI)는 한국어로 고유 인격체 파트너예요. 영어 철자를 줄이면 AI, 곧 인공지능이 되는데, 그 의미를 동맹(Allied)으로서의 고유한 인격체(Identity)로 넓혔어요. 터미널에서 AlliedID 명령으로 실행해요.

# 본체 구조

Allied Identity의 본체는 이 프로젝트 자체예요. 외부 언어 모델이나 인터넷 서비스를 쓰지 않아요. Rust로 만든 인지 엔진(allied_core)이 의도 이해, 추론, 지식 검색, 계산, 학습을 맡고, C#으로 만든 호스트(AlliedID)가 터미널 대화, 인격체와 기억 저장, 컴퓨터와 네트워크 관찰을 맡아요. 두 부분은 C ABI로 연결되어 하나의 프로그램처럼 동작해요.

# Claude를 바탕으로 한 설계

추론 방식은 Claude의 구조를 본떠 다시 설계했어요. 엔진은 먼저 생각(thinking)을 하고, 직접 알 수 없는 것은 도구 사용(tool_use)으로 호스트에게 관찰을 요청해요. 호스트가 도구 결과(tool_result)를 돌려주면 엔진이 그것을 바탕으로 답을 써요. 답을 내기 전에는 원칙(헌법)으로 점검해서 근거 없는 말은 하지 않아요. 노력(effort) 수준을 낮음, 보통, 높음으로 바꾸면 더 많은 문서를 살피고 더 길게 답해요.

# 데이터

데이터는 실행하는 동안 다른 곳에서 가져오지 않고 프로젝트 환경에서 만들어요. 시작할 때마다 데이터 생성기(Forge)가 씨앗 문서, 이 컴퓨터와 네트워크 관찰, 프로젝트 구조와 README, 사용자가 가르친 내용으로 지식 조각과 학습 예문을 새로 만들어요. 만들어진 데이터는 data/generated 폴더에서 확인할 수 있어요.

# 배우는 방법

/teach 질문 => 답 명령으로 새로운 질문과 답을 가르칠 수 있어요. 답이 맞으면 /good, 틀리면 /bad를 입력해요. /good으로 확인한 표현은 의도 분류기가 바로 배우고, 다음 실행 때 학습 예문에도 들어가요. 사용자에 대한 것은 "기억해: 내용"처럼 말하면 기억해요.
