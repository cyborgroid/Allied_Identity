# 네트워크 환경 점검

Allied Identity는 Wi-Fi와 네트워크 정보를 인터넷 사용이 아니라 지금 이 컴퓨터가 어떤 네트워크에 노출되어 있는지 파악하는 데 써요. 인터넷이 없어도 본체는 그대로 동작해요.

# 개방형 Wi-Fi

개방형 Wi-Fi는 암호가 없는 무선 네트워크예요. 개방형 Wi-Fi에서는 같은 네트워크의 다른 기기가 암호화되지 않은 트래픽을 볼 수 있어서 위험해요. 카페나 공항의 공용 Wi-Fi에서는 HTTPS 사이트만 쓰고, 가능하면 VPN을 켜세요.

# Wi-Fi 보안 방식

WEP나 TKIP 같은 오래된 보안 방식은 쉽게 뚫려요. 공유기 설정에서 WPA2 이상, 가능하면 WPA3로 바꾸는 것이 안전해요.

# 캡티브 포털

캡티브 포털은 Wi-Fi에 연결한 뒤 로그인이나 약관 동의를 해야 인터넷이 열리는 페이지예요. Wi-Fi에 연결되어 있는데 인터넷이 안 되면 브라우저를 열어 캡티브 포털이 있는지 확인해 보세요.

# Wi-Fi 신호

신호가 30% 미만이면 약한 편이에요. 공유기 가까이 이동하거나, 벽이 많으면 5GHz 대신 멀리 가는 2.4GHz 대역을 쓰세요.

# 셀룰러 데이터와 테더링

모바일 데이터는 통신사가 SIM과 요금제를 통해 제공하는 인터넷이에요. 휴대폰 테더링이나 LTE, 5G 모뎀을 쓰면 요금제의 데이터가 소모돼요. Allied Identity는 셀룰러나 테더링 경로를 감지하면 알려 드려요.
